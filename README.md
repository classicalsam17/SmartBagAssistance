# 🎒 Smart Bag Assistant

A C++ OOP-based microproject that helps students prepare their college bag according to their daily timetable.

Smart Bag Assistant allows students to create a profile, maintain their timetable, select their practical batch, and generate the required bag items for a selected date. The application also allows users to mark items as packed, add additional items, view their profile and timetable, and save their data for future use.

## 📌 Project Overview

Students often forget notebooks, journals, practical files, or other items required for their college sessions.

Smart Bag Assistant provides a simple solution by connecting the student's timetable with the items required for each lecture or practical.

The user enters a date, and the application determines the corresponding day and generates the required bag items based on the timetable.
